# 🚀 RevoU Mini Project – Company Profile Website

> Mini Project submission for RevoU Software Engineering Mini Course.

---

## 📌 Project Description

As part of the RevoU Mini Course, this project requires building a **Company Profile Website** that includes:

- Home Page
- Our Profile Page
- Message Us (Contact Form)
- JavaScript form validation
- Responsive Design (Desktop & Mobile)

The website is developed based on the provided mockup and additional creativity while still fulfilling the required structure.

---

## 🎯 Project Objectives

- Build a company profile website using HTML, CSS, and JavaScript
- Implement JavaScript validation on the contact form
- Create dynamic greeting message on Home Page using JavaScript
- Apply responsive design principles
- Follow project structure and branching instructions
- Deploy the project using GitHub Pages

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Git & GitHub
- GitHub Pages (Deployment)
